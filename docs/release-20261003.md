# Integrated release — 3 October 2026

- Production uses durable evaluation jobs for all five tests, with status polling and results recoverable from History.
- Account-scoped submission keys remain available through errors, reloads and access-token renewal. Evaluation writes are never retried automatically.
- History loads 50 records at a time with older pages. Summary cards in the dashboard, history, analytics and profile use lifetime server totals. Distribution/trend charts describe the loaded sample; all graphs remain available.
- Browser sessions renew with a Secure, HttpOnly refresh cookie through a same-origin proxy. Refresh tokens are never stored in browser localStorage.
- Password recovery accepts an emailed code and a new password.
- Signup submits exact published policy versions after explicit unchecked consent. Profile supports policy review and reacceptance when approved documents are available.
- Sites publication includes a Worker proxy to the Azure API; Vercel retains its existing rewrite configuration. The proxy sends only the app refresh cookie and discards browser-supplied forwarding headers.
